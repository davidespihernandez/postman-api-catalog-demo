This guide walks you through creating your first order against the **Orders API**. The request and
response snippets below are generated **directly from the OpenAPI spec** — so they stay accurate as
the API evolves, with no copy-paste drift.

<Note>
All examples target the live demo server: `https://18-157-170-15.nip.io`. No authentication is
required for this demo environment.
</Note>

<Steps>
  <Step title="Pick your base URL">
    Every endpoint in this portal is relative to the server URL above. You can call it with `curl`,
    any SDK, or straight from the **Try it** button on each snippet.
  </Step>

  <Step title="Create an order">
    Send a `POST /orders` with the customer and total. Only `customerId` and `total` are required;
    `status` and `currency` are optional.

    <EndpointRequestSnippet endpoint="POST /orders" />
  </Step>

  <Step title="Inspect the response">
    A successful call returns the created order, including its server-assigned `id`. Copy that `id`
    for the next step.

    <EndpointResponseSnippet endpoint="POST /orders" />
  </Step>

  <Step title="Read the order back">
    Fetch the order you just created with `GET /orders/{id}`.

    <EndpointRequestSnippet endpoint="GET /orders/{id}" />
  </Step>
</Steps>
