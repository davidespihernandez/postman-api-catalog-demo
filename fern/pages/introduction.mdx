Welcome to the developer portal for the **Postman API Catalog demo**. Three small REST
APIs — **Orders**, **Payments**, and **Users** — self-hosted on AWS, documented straight
from the same OpenAPI specs that power the Postman workspace and the CI/CD pipeline.

## Base URL

All three APIs are served under one host, path-routed:

```
https://18-157-170-15.nip.io
```

| API | Path | Try it |
|-----|------|--------|
| Orders | `/orders` | see **Orders API** in the API Reference |
| Payments | `/payments` | see **Payments API** |
| Users | `/users` | see **Users API** |
| Health | `/health` | `GET https://18-157-170-15.nip.io/health` |

<Note>
This is a demo API — **no authentication is required**. Use the **API Explorer** in the
API Reference to send live requests against the running backend.
</Note>

## One contract, many outputs

The `orders.yaml`, `payments.yaml`, and `users.yaml` OpenAPI specs are the single source
of truth. The same files:

- power this **Fern developer portal**,
- are published to the **Postman workspace** (Spec Hub + collections),
- and can generate **SDKs** via `fern generate`.

Download any spec from its API Reference page and import it into Postman to explore it there too.
