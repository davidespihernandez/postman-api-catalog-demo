Welcome to the **Retail Commerce** developer portal. The **Orders**, **Payments**, and **Users**
APIs power the Retail Commerce platform — everything you need to build checkout, fulfillment,
and customer-account experiences.

## Base URL

All three APIs are served under one host, path-routed:

```
https://18-157-170-15.nip.io
```

| API | Path | Try it |
|-----|------|--------|
| Orders | `/orders` | see **Orders API** in the API Reference |
| Payments | `/payments` | see **Payments API** |
| Users | `/users` | see **Users API** |
| Health | `/health` | `GET https://18-157-170-15.nip.io/health` |

<Note>
No authentication is required in this **sandbox** environment. Use the **API Explorer** in the
API Reference to send live requests against the running service.
</Note>

## Built from OpenAPI

Every endpoint on this portal is generated from our OpenAPI specifications, so the docs always
match the live API. **Download the OpenAPI spec** from any API Reference page to generate SDKs
in your language of choice or import it into your API client.
