## Quick call

Every endpoint is live — no auth required. For example:

```bash
curl https://18-157-170-15.nip.io/orders
```

<Note>
One OpenAPI contract, many outputs: the same specs drive this portal, the **Postman**
workspace, and generated **SDKs**. Download any spec from its API Reference page and import
it into Postman.
</Note>
