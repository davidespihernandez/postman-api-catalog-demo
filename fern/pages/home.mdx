## Make your first call

Every endpoint is live in the sandbox — no authentication required. For example:

```bash
curl https://18-157-170-15.nip.io/orders
```

<Note>
Prefer working in your own tools? Download the OpenAPI spec from any API Reference page to
generate SDKs or import it into your API client.
</Note>
